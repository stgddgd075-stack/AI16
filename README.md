# باگی تام — Ultimate Edition

🎮 بازی سه‌بعدی پلتفرمر ساخته شده با Three.js

**ساخته امیرحسین پهلوان**

## ویژگی‌ها
- ۲۷ مرحله + ۶ باس
- دو قهرمان (آرش و آوا)
- سیستم مهارت، فروشگاه، دستاوردها
- حالت بی‌پایان، چالش روزانه، مسابقه زمانی
- کنترل لمسی + کیبورد

## اجرا
1. فایل `index.html` را دانلود کنید یا از منبع اصلی استفاده کنید.
2. فایل را در مرورگر باز کنید (Chrome/Edge توصیه می‌شود).
3. یا یک سرور محلی اجرا کنید:
```bash
python3 -m http.server 8080
```
سپس به `http://localhost:8080` بروید.
